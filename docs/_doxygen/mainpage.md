# TMC5160 Driver API reference {#mainpage}

The classes, types and registers of the TMC5160 driver, generated from the headers in `inc/`.

Start with tmc5160::TMC5160, the driver, and tmc5160::SpiInterface, the base of the port you write. Errors are
tmc5160::Error inside tmc5160::Result; the configuration is tmc5160::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">TMC5160 Driver
documentation</a>.
