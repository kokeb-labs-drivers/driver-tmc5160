Datasheet map¶

The driver follows the TMC5160 datasheet. This page says which revision, where to get it, and where each part of the driver is described in it, so you can check any behaviour against the source. Section names and page numbers are the datasheet's own (the printed page numbers).

  • Datasheet: TMC5160 / TMC5160A Datasheet, Analog Devices (Trinamic) TMC5160A-DS, revision 1.18 (2023-03-01). Get it from the vendor page. SHA-256 of the file used: 3c3edc4fbd694f3afd95ff8f5922a777fdc56d91660c3c0fbdccc016f1bd0be1.

When the datasheet and the driver differ¶

The driver is written against the revision above. If you have a newer revision, compare its revision history with the topics above; a change to a pin, a register, a timing or a value the driver uses is a bug report for this repository. Where the driver deliberately goes beyond the datasheet, the Contract says so.

The repository never contains the PDF itself: vendors own their documents. Download it from the vendor, and compare its SHA-256 with the one above to confirm you have the same file.
