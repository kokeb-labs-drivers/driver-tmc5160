Detailed Description

Pure integer conversions between datasheet register units and physical units, and the current plan that ties the coil current to the declared motor and sense resistor.

Copyright
Copyright (c) 2026 The driver-tmc5160 authors. SPDX-License-Identifier: MIT

Every function is constexpr, integer only, allocates nothing and does no I/O. All times, velocities and accelerations scale with the clock frequency fclk_hz (section 12.1, page 81). Products that can exceed 64 bits are split in two steps; the result is within one unit of the exact quotient.

◆ PlanCurrent()

constexpr Result< CurrentPlan > tmc5160::units::PlanCurrent ( const Config &  config,
uint32_t  run_ma,
uint32_t  hold_ma 
)
constexprnoexcept

Turn a run and hold current request into register values, or refuse it.

The run and hold current, rounded down, must stay at or under the ceiling min(max_rms_ma, rated_rms_ma), reduced by the 5 percent tolerance when include_tolerance is set (section 9 page 74, 28.2 page 123), and the sense resistor must be able to carry the run current. GLOBALSCALER is chosen from 129 to 256 (page 36 recommends above 128).

Parameters
configThe configuration (motor, board, tolerance, acknowledgements).
run_maRequested run current, RMS mA.
hold_maRequested hold current, RMS mA.
Returns
The plan, LimitExceeded (ceiling or sense resistor), Refused (hold above run without Ack::HoldAboveRun) or InvalidArgument (a zero request or a missing sense resistor).
