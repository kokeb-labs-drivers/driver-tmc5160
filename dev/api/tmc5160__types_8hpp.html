Detailed Description

Public types of the TMC5160 driver: errors, Result<T>, configuration, validation and advice.

Copyright
Copyright (c) 2026 The driver-tmc5160 authors. SPDX-License-Identifier: MIT

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the chip's reset values (TMC5160 datasheet, chapter 6). Config{} is deliberately not valid: the motor and the power stage must be declared, because the coil current follows from the sense resistor and the declared motor limits.
