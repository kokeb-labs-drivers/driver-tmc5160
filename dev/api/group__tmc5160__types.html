◆ Error

enum class tmc5160::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false.

Timeout 

The chip did not answer in the allowed time or a bounded wait ran out.

DeviceIdMismatch 

IOIN.VERSION is not 0x30: another chip, no chip or a wiring fault.

Crc 

The CRC-8 of a UART reply did not match (never produced on SPI).

Busy 

The motor is moving or a ramp is running: the call needs standstill.

DeviceFault 

The driver reports an error (GSTAT.drv_err): short or overtemperature.

Unsupported 

The hook, bus or mode this call needs is absent.

UnexpectedReset 

The chip reset (GSTAT.reset, SPI status bit 0): every write-only register is lost.

VerifyFailed 

A write-back, echo or interface-counter check did not match.

Refused 

A guard refused the call: a missing acknowledgement or an unsafe order.

ModeMismatch 

The SD_MODE strap or the bus does not match Config::mode.

LimitExceeded 

The request exceeds a declared motor, board or ramp limit.

◆ Validate()

constexpr Error tmc5160::Validate ( const Config &  config)
constexprnoexcept

Check a configuration without touching the chip.

Rejects every combination the datasheet forbids: the declared motor and power stage are missing or out of range, a field is out of range, the chopper, thresholds, ramp, bridge, diag or table rules of section 2.5 of the design are broken. Rules that need a current plan (the ceiling) are checked by PlanCurrent().

Parameters
configThe configuration.
Returns
Error::Ok or Error::InvalidArgument.
