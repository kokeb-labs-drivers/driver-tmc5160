Detailed Description

The SPI port of the TMC5160 driver: the CRTP base, the SpiPort concept and the bus requirements.

The driver never calls an SDK. It calls hooks on a class you derive from tmc5160::SpiInterface<Self>:

Hook Contract
bool EnsureInitialized() noexcept Bring the bus up on the first call; true at once afterwards
bool Transfer(const uint8_t* tx, uint8_t* rx, std::size_t len) noexcept One full-duplex transfer, CSN low for all len bytes, SPI mode 3, MSB first; len is 5 x the chain length; both buffers are given

The port moves raw bytes: it never retries, never interprets a datagram and never configures the chip. DelayUs, GpioSet, GpioGet, SckHz and Log are optional hooks described in tmc5160.hpp.
